# gerador-de-senha
Este projeto é um gerador de senhas simples e eficiente, desenvolvido para criar senhas seguras de forma rápida. O usuário pode escolher o tamanho da senha e quais tipos de caracteres deseja incluir, como letras maiúsculas, minúsculas, números e símbolos.

Funcionalidades:
- Definição do tamanho da senha
- Geração de senhas fortes
- Interface simples e intuitiva
- Visualização imediata da senha gerada
- Efeito de destaque ao passar o mouse na senha
- Clique na senha para copiar
- Tooltip de confirmação ao copiar
- Responsividade

Link do projeto: https://gerador-de-senha-pi-jet.vercel.app/
